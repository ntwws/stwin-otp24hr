# OTP24HR Updates

- ดาวน์โหลดล่าสุด: [OTP24HR-portable.zip](./OTP24HR-portable.zip)
- ข้อมูลเวอร์ชันและ SHA-256: [update.json](./update.json)
- โปรแกรมตรวจสอบลายเซ็น Ed25519 และ SHA-256 อัตโนมัติก่อนติดตั้งทุกครั้ง
